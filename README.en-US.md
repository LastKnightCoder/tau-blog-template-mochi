# Mochi Shop

A cute yet calm Tau blog template that turns your blog into a cozy wagashi shop. A mochi mascot greets visitors, reacts when poked, and naps beside your articles, while your articles, cards, and project docs stay clean and easy to read.

## Get Started in 3 Steps

1. **Install the template**: Install **Mochi Shop** from the Plugin Center.
2. **Choose the template**: Open **Publish › Site Settings › Blog Template** in the Sidebar and select **Mochi Shop**.
3. **Customize and publish**: Fill in your site description and customize the mochi's look and lines as you like, save, then choose the content to publish.

## Pages

| Page          | What visitors see                                                                                    |
| ------------- | ---------------------------------------------------------------------------------------------------- |
| Home          | Your site title, the mochi sitting on a sakura circle, entry links for Articles, Cards, and Projects, and recent updates |
| Articles      | A collapsible, searchable tag tree on the left, with articles grouped by year on the right           |
| Article       | Table of contents and reading progress on the left, and a napping mochi in the right margin that wakes up when you finish |
| Cards         | The same tag tree on the left, paired with a monthly sweet-box grid on the right                     |
| Card detail   | The same comfortable reading layout as articles, with linked cards listed in the right column        |
| Project docs  | A hairline table of contents marking read pages, with previous and next page navigation              |
| Not found     | A dizzy mochi that guides visitors back to the home page when an address does not exist              |

## Site Settings

Configure these options under **Publish › Site Settings › Blog Template** in the Sidebar:

| Field                  | Description                                                                        |
| ---------------------- | ---------------------------------------------------------------------------------- |
| Site description       | Shown below the site title on the home page; hidden when left blank                |
| Mochi's name           | Used in the shop seal, home greeting, and not-found page; defaults to "Mochi"      |
| Mochi's color          | Choose from Sakura, Matcha, Shiro (white), or Kuri (chestnut)                      |
| Mochi's lines          | Shown in rotation when visitors poke the mochi, one line per row; uses default lines if left blank |
| Mochi's ambient motion | Controls blinking and pointer tracking on the home page; turn off to keep the mochi still |

## FAQ

**Will existing links break if I switch from another template?** No. Mochi Shop uses the same page paths as the official **Tau Blog** template, so links you have already shared keep working.

**How can visitors search my blog?** Press `⌘K` (`Ctrl K` on Windows) on any page, or click the search button in the header, to search across articles, cards, and projects.

**Can animations be turned off?** Yes. In addition to turning off **Mochi's ambient motion** in Site Settings, when a visitor's system has **Reduce Motion** enabled, all animations finish immediately and the mochi's eyes stop following the pointer.

**Does it support dark mode?** Yes. Visitors can switch between light and dark appearance anytime with the day/night toggle.
