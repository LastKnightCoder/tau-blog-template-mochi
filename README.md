# 团子铺

可爱而安静的 Tau 博客模板，把你的博客装扮成一家和果子小店。一只会看你、能被戳、会打盹的团子替你迎客，文章、卡片和项目文档都会以清爽舒适的排版呈现。

## 三步开始

1. **安装模板**：在插件中心安装「团子铺」。
2. **选用模板**：打开侧边栏的「发布 › 站点设置 › 博客模板」，选择「团子铺」。
3. **填写设置并发布**：按需要填写站点描述和团子的外观与台词，保存后勾选要公开的内容即可发布。

## 页面一览

| 页面       | 展示内容                                                             |
| ---------- | -------------------------------------------------------------------- |
| 首页       | 站名、坐在樱色圆上的团子、文章 / 卡片 / 项目分区入口与最近更新的内容 |
| 文章目录   | 左侧为可折叠、可搜索的标签树，右侧按年份分段排列文章                 |
| 文章详情   | 左侧显示目录与阅读进度，右侧页边有一只打盹的团子，读完后会醒来       |
| 卡片列表   | 沿用同一套标签树，右侧以按月分格的点心盒展示卡片                     |
| 卡片详情   | 与文章一致的阅读排版，右栏列出相关联的卡片                           |
| 项目文档   | 左侧细线目录标出已读页面，底部支持上一页、下一页翻阅                 |
| 找不到页面 | 访客打开不存在的地址时，出现一只晕乎乎的团子引导返回首页             |

## 站点设置

在侧边栏「发布 › 站点设置 › 博客模板」中，可以按喜好配置下面这些选项：

| 字段         | 说明                                             |
| ------------ | ------------------------------------------------ |
| 站点描述     | 显示在首页站名下方，留空则不显示                 |
| 团子的名字   | 用在店印、首页问候和找不到页面时，默认为「团子」 |
| 团子的颜色   | 可选樱花、抹茶、白玉、栗子                       |
| 团子的口头禅 | 访客戳团子时轮流显示，每行写一句，留空用默认台词 |
| 团子的小动作 | 控制首页团子眨眼和跟着鼠标看，关掉后团子保持静止 |

## 常见问题

**从其他模板换过来，以前的链接会失效吗？** 不会。团子铺与官方「Tau 博客」模板使用相同的页面路径，换模板后已分享的旧链接依然有效。

**访客怎么在博客里搜索内容？** 在任意页面按 `⌘K`（Windows 上按 `Ctrl K`），或点击页头的搜索入口，就能搜索站内的文章、卡片和项目。

**可以关闭动画效果吗？** 可以。除了在站点设置里关闭「团子的小动作」之外，当访客的系统开启「减弱动态效果」时，站内所有动画都会瞬间完成，团子的眼睛也不再跟随鼠标。

**支持深色模式吗？** 支持。站内提供日夜模式切换，访客可以随时在浅色与深色外观之间切换。
