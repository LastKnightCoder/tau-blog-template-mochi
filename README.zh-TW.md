# 糰子舖

可愛而安靜的 Tau 部落格模板，把你的部落格裝扮成一家和菓子小店。一隻會看著你、可以被戳、會打盹的糰子替你迎客，文章、卡片和專案文件都會以清爽舒適的排版呈現。

## 三步開始

1. **安裝模板**：在外掛中心安裝「糰子舖」。
2. **選用模板**：開啟側邊欄的「發佈 › 站點設定 › 部落格模板」，選擇「糰子舖」。
3. **填寫設定並發佈**：依需要填寫站點描述以及糰子的外觀與台詞，儲存後勾選要公開的內容即可發佈。

## 頁面一覽

| 頁面       | 展示內容                                                             |
| ---------- | -------------------------------------------------------------------- |
| 首頁       | 站名、坐在櫻色圓上的糰子、文章 / 卡片 / 專案分區入口與最近更新的內容 |
| 文章目錄   | 左側為可收合、可搜尋的標籤樹，右側依年份分段排列文章                 |
| 文章詳情   | 左側顯示目錄與閱讀進度，右側頁邊有一隻打盹的糰子，讀完就會醒來       |
| 卡片列表   | 沿用同一套標籤樹，右側以依月份分格的點心盒展示卡片                   |
| 卡片詳情   | 與文章一致的閱讀排版，右欄列出相關聯的卡片                           |
| 專案文件   | 左側細線目錄標出已讀頁面，底部支援上一頁、下一頁翻閱                 |
| 找不到頁面 | 訪客開啟不存在的網址時，出現一隻暈乎乎的糰子引導返回首頁             |

## 站點設定

在側邊欄「發佈 › 站點設定 › 部落格模板」中，可以依喜好設定以下選項：

| 欄位         | 說明                                             |
| ------------ | ------------------------------------------------ |
| 站點描述     | 顯示在首頁站名下方，留空則不顯示                 |
| 糰子的名字   | 用於店印、首頁問候與找不到頁面時，預設為「糰子」 |
| 糰子的顏色   | 可選櫻花、抹茶、白玉、栗子                       |
| 糰子的口頭禪 | 訪客戳糰子時輪流顯示，每行寫一句，留空用預設台詞 |
| 糰子的小動作 | 控制首頁糰子眨眼與跟隨滑鼠看，關閉後糰子保持靜止 |

## 常見問題

**從其他模板換過來，以前的連結會失效嗎？** 不會。糰子舖與官方「Tau 部落格」模板使用相同的頁面路徑，切換模板後已分享的舊連結依然有效。

**訪客怎麼在部落格裡搜尋內容？** 在任意頁面按 `⌘K`（Windows 上按 `Ctrl K`），或點擊頁首的搜尋入口，就能搜尋站內的文章、卡片與專案。

**可以關閉動畫效果嗎？** 可以。除了在站點設定裡關閉「糰子的小動作」之外，當訪客的系統開啟「減少動態效果」時，站內所有動畫都會瞬間完成，糰子的眼睛也不再跟隨滑鼠。

**支援深色模式嗎？** 支援。站內提供日夜模式切換，訪客可以隨時在淺色與深色外觀之間切換。
